
GAN(Generative Adversarial Network)에서 "적대적(Adversarial)"이라는 용어가 사용된 이유는 두 개의 신경망(생성자와 판별자)이 서로 경쟁하는 구조를 가지기 때문임
이 네트워크는 게임 이론적인 관점에서 제로섬 게임(Zero-Sum Game)처럼 동작하며, 두 신경망이 서로를 속이고 학습하면서 점점 더 정교한 데이터를 생성하도록 설계됨

#### 1.  GAN의 기본 구조와 적대적 학습

- **생성자(Generator, G)**: 실제 데이터를 흉내 내는 가짜 데이터를 생성하는 역할을 수행하며, 처음에는 무작위로 데이터를 생성하지만, 점점 더 판별자를 속일 수 있도록 학습됨 
- **판별자(Discriminator, D)**: 입력된 데이터가 진짜(실제 데이터)인지 가짜(생성된 데이터)인지 판별하는 역할을 수행 
- 이 두 신경망은 상대방을 속이거나 더 정확하게 판별하기 위해 서로 학습하는 과정을 거침

#### 2. **적대적(Adversarial)이라는 용어의 의미**

- 생성자는 판별자를 속이기 위해 점점 더 진짜 같은 데이터를 만들어야 하고, 판별자는 속지 않기 위해 더 정교하게 진짜와 가짜를 구별하는 능력을 키워야 함
- 이 과정이 마치 적대적인 관계(Adversarial Relationship)처럼 보이기 때문에 "적대적 신경망"이라는 용어가 사용됨
- GAN은 이러한 적대적 훈련을 반복하면서 생성자가 점점 더 사실적인 이미지, 음성, 텍스트 등을 생성할 수 있도록 발전함

#### 3. **비유적인 설명**

GAN의 학습 과정은 위조지폐범(생성자)과 경찰(판별자)의 관계로 자주 비유됨

- 위조지폐범(생성자)은 경찰(판별자)의 감시를 피해 더욱 정교한 위조지폐를 만들려고 함
- 경찰(판별자)은 위조지폐를 감별하는 능력을 계속 발전시킴
- 이 과정이 반복될수록, 위조지폐는 점점 더 진짜 같아지고, 경찰도 더욱 정밀한 감별 기술을 습득함
- 결국, 위조지폐범이 만들어낸 지폐가 실제 지폐와 구별하기 어려울 정도로 정교해지듯이, GAN 모델도 매우 사실적인 데이터를 생성할 수 있게 됨

GAN에서 "적대적"이라는 표현이 사용된 이유는 생성자와 판별자가 서로를 속이고 극복하는 경쟁적 학습 방식을 사용하기 때문이며, 이 과정에서 두 네트워크가 서로 발전하면서 최적의 생성 모델을 만듦 
이러한 적대적 학습 구조 덕분에 GAN은 기존의 생성 모델보다 훨씬 현실적인 데이터를 만드는 것이 가능해짐
