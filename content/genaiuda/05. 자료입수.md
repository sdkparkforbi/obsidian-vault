### **(9) 데이터 정리 (이모지 제거, UTF-8 문자 깨짐 방지)**


`def remove_emoji(text):     emoji_pattern = re.compile("[\U0001F600-\U0001F64F\U0001F300-\U0001F5FF]+", flags=re.UNICODE)     return emoji_pattern.sub(r'', text)`

- **기사 본문에서 이모지를 제거하여 DB 저장 시 오류 방지**

`def truncate_content(content, max_bytes=65535):     if not content:         return ""     encoded = content.encode('utf-8')     if len(encoded) <= max_bytes:         return content     truncated = encoded[:max_bytes]     while len(truncated) > 0 and truncated[-1] & 0b11000000 == 0b10000000:         truncated = truncated[:-1]     return truncated.decode('utf-8', errors='ignore')`

- **UTF-8 문자 깨짐 방지를 위해 65,535 바이트를 초과하는 경우 문자가 잘리지 않도록 조정**
