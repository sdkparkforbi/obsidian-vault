
## 개요: AI 활용 방식의 구분

|활용 방식|특징|적합한 작업|
|---|---|---|
|**UI 활용**|대화형 인터페이스 (ChatGPT, Claude 등)|아이디어 생성, 글쓰기, 코딩 지원, 해석|
|**API 활용**|프로그래밍으로 대량 자동 처리|대량 문서 처리, 반복 작업, 파이프라인 구축|

---

## 연구 단계별 AI 활용 매핑

### 1. 기획 단계 (Planning)

|연구방법론 영역|AI 활용|방식|구체적 활용|
|---|---|---|---|
|**연구의 중요성**|기획 지원|UI|트렌드 파악, 이슈 탐색, 배경 정보 검색|
|**선행연구 검토**|정보 검색|UI|문헌 요약, 연구 동향 파악, 갭 탐색|
||문서 필터링|API|대량 논문 스크리닝, 관련성 판단|
||메타 추출|API|논문에서 저자, 연도, 방법론, 결과 추출|
|**연구 목적/가설**|설계 지원|UI|연구 질문 정제, 가설 구체화|
|**방법론 설계**|설계 지원|UI|연구 설계 자문, 분석 방법 추천|
|**데이터 수집 계획**|설계 지원|UI|데이터 소스 탐색, 수집 전략 수립|

---

### 2. 실행 단계 (Execution)

|연구방법론 영역|AI 활용|방식|구체적 활용|
|---|---|---|---|
|**자료 수집**|코딩 지원|UI|웹스크래핑 코드, API 호출 코드 작성|
||문서 필터링|API|수집된 뉴스/논문/특허/규제문서 필터링|
||메타 추출|API|비정형 텍스트에서 구조화된 정보 추출|
|**자료 분석**|코딩 지원|UI|통계 분석 코드, ML/DL 모형 구현|
||방법론 구현|UI|알고리즘 설명, 디버깅, 최적화|
|**결과 도출**|결과 해석|UI|통계 결과 해석, 그래프/표 설명|
||시각화 지원|UI|시각화 코드 생성, 그래프 개선|

---

### 3. 논문 작성 단계 (Writing)

|논문 섹션|AI 활용|방식|구체적 활용|
|---|---|---|---|
|**서론**|논문 작성|UI|배경 서술, 문헌 정리, 논리 구조화|
|**방법**|논문 작성|UI|방법론 기술, 용어 정리|
|**결과**|결과 해석|UI|표/그림 설명, 결과 서술|
|**고찰/결론**|논문 작성|UI|해석 정교화, 제한점 도출, 제언 작성|
|**초록/제목**|논문 작성|UI|요약, 키워드 추출|
|**영문 교정**|논문 작성|UI|문법 교정, 학술적 표현 개선|

## UI vs API 활용 비교

```
┌─────────────────────────────────────────────────────────────┐
│                    생성형 AI 활용 방식                        │
├─────────────────────────────┬───────────────────────────────┤
│         UI 활용              │          API 활용             │
│    (대화형, 단건 처리)         │     (자동화, 대량 처리)        │
├─────────────────────────────┼───────────────────────────────┤
│ • 기획 지원                   │ • 문서 필터링 (대량)           │
│ • 정보 검색                   │ • 메타 추출 (대량)             │
│ • 설계 지원                   │ • 반복적 분류/판단             │
│ • 코딩 지원                   │ • 파이프라인 내 LLM 호출       │
│ • 결과 해석                   │                              │
│ • 논문 작성                   │                              │
└─────────────────────────────┴───────────────────────────────┘
```

## 전체 흐름도: AI 활용 연구 파이프라인

```
[기획 단계]
    │
    ├── 연구의 중요성 ────── UI: 트렌드/이슈 탐색
    │
    ├── 선행연구 ─────────── UI: 문헌 요약
    │                       API: 대량 논문 필터링, 메타 추출
    │
    ├── 연구 목적 ────────── UI: 질문/가설 정제
    │
    └── 방법론 설계 ──────── UI: 설계 자문, 방법 추천
                │
                ▼
[실행 단계]
    │
    ├── 자료 수집 ────────── UI: 스크래핑/API 코드 작성
    │                       API: 문서 필터링, 메타 추출
    │
    ├── 자료 분석 ────────── UI: 분석 코드, 모형 구현
    │
    └── 결과 도출 ────────── UI: 결과 해석, 시각화
                │
                ▼
[논문 작성]
    │
    ├── 서론 ─────────────── UI: 배경, 문헌, 목적 서술
    ├── 방법 ─────────────── UI: 방법론 기술
    ├── 결과 ─────────────── UI: 표/그림 설명
    └── 결론 ─────────────── UI: 해석, 제한점, 제언
```

## 정리: 기존 연구방법론의 AI 보완 영역

|기존 방법론의 한계|AI 보완|활용 방식|
|---|---|---|
|문헌검토에 시간 과다 소요|대량 문헌 자동 스크리닝|API|
|비정형 데이터 처리 어려움|텍스트에서 메타 정보 추출|API|
|데이터 수집 기술 장벽|스크래핑/API 코드 생성|UI|
|통계/ML 코딩 장벽|분석 코드 생성 및 디버깅|UI|
|결과 해석의 주관성|객관적 해석 보조|UI|
|논문 작성 시간 과다|초안 작성, 문장 개선|UI|
|영문 교정 비용|문법/표현 교정|UI|

---

## 핵심 메시지

> **UI는 "생각의 파트너"** — 기획, 해석, 작성 지원 **API는 "자동화 엔진"** — 대량 처리, 반복 작업, 파이프라인 구축

두 방식을 적절히 조합하면 연구 효율성을 극대화할 수 있다
