# 04. 선형회귀 (Linear Regression)

> 실습 노트북: `MB4_DK.ipynb` · 데이터: 마케팅(marketing)

## 이 장에서 배우는 것

**선형회귀**는 한 변수(반응변수 Y)를 다른 변수(설명변수 X)들의 직선식으로 설명·예측하는 가장 기본적인 모형임. 이 장에서는 마케팅 지출로 매출을 설명하는 모형을 세우고, 그 모형이 믿을 만한지 **가정을 진단**하며, 미래 매출을 **예측**함.

1. 단순 선형회귀(SLR) 적합과 해석
2. 회귀 가정 진단: 정규성·등분산성·자기상관
3. 예측과 신뢰·예측구간
4. 데이터 변환과 이상치/영향점 처리
5. 다중 선형회귀(MLR)

## 1. 단순 선형회귀 (Simple Linear Regression)

```r
par(mfrow = c(1, 1))
pairs(adverts)        # 변수 쌍 산점도로 관계 개관
plot(adverts$marketing_total, adverts$revenues,
     ylab = "Revenues", xlab = "Marketing Total", main = "Revenues and Marketing")
```

먼저 산점도로 "마케팅 총액이 늘면 매출도 느는" 직선 경향을 눈으로 확인함.

```r
model1 <- lm(revenues ~ marketing_total, data = adverts)
model1            # 회귀계수(절편, 기울기)
summary(model1)   # 자세한 결과
```

- `lm(Y ~ X, data = ...)`: **Y를 X로 설명**하는 선형회귀를 적합함 (`revenues = β0 + β1 × marketing_total + ε`)
- `summary()` 읽는 법:
  - **Estimate**: 절편(β0)과 기울기(β1). 기울기는 "X가 1 늘 때 Y가 평균 얼마 변하는가"
  - **Pr(>|t|)**: 각 계수의 유의확률(작을수록 유의)
  - **R-squared**: 모형이 Y의 변동을 얼마나 설명하는지(0~1, 클수록 설명력 큼)
  - **F-statistic의 p-value**: 모형 전체의 유의성

### 잔차(Residuals)의 개념

```r
plot(adverts$marketing_total, adverts$revenues,
     ylab = "Revenues", xlab = "Marketing",
     main = "Revenues versus Marketing", xlim = c(50, 150), xaxt = "n")
abline(model1)
segments(x0 = 53.6, y0 = 31.0, x1 = 53.6, y1 = 34.68, lwd = 2, lty = 3)
text(x = 57.5, y = 30.5, labels = "A")   # A: 실제값(Actual)
text(x = 54.0, y = 36.3, labels = "P")   # P: 예측값(Predicted)
axis(1, at = c(53.6, 100, 150, 200, 250))
```

**잔차 = 실제값(A) − 예측값(P)**. 회귀직선은 이 잔차들의 제곱합이 가장 작아지도록 그어짐(최소제곱법). 점선이 A와 P의 차이, 즉 잔차를 나타냄.

## 2. 회귀 가정 진단 (Checking Model Assumptions)

선형회귀 결과를 믿으려면 **잔차가 다음 세 가정**을 만족해야 함.

### (1) 정규성(Normality) — 잔차가 정규분포를 따르는가

```r
par(mfrow = c(1, 2))
hist(model1$residuals, xlab = "Residuals", col = "gray", main = "Residuals Distribution")
qqnorm(model1$residuals, main = "Q-Q Plot of Residuals"); qqline(model1$residuals)
```

- 히스토그램이 종 모양인지, Q-Q plot의 점들이 직선에 붙는지 확인함

```r
# Jarque-Bera 정규성 검정 (수치적 확인)
install.packages("/content/drive/MyDrive/bizbig/ch4/data/normtest_1.1.tar.gz", repos = NULL, type = "source")
library(normtest)
jb.norm.test(model1$residuals)
```

`jb.norm.test()`의 **p-value가 크면(>0.05)** "정규분포가 아니다"를 기각하지 못함 → 정규성 가정 OK.

### (2) 등분산성(Equal Variance) — 잔차의 퍼짐이 일정한가

```r
par(mfrow = c(1, 1))
plot(model1$fitted.values, model1$residuals,
     ylab = "Residuals", xlab = "Fitted Values", main = "Residuals Distribution")
abline(0, 0, lwd = 3); abline(h = c(-6.5, 6.5), lwd = 3, lty = 3)

# Breusch-Pagan 검정
install.packages(c("lmtest", "sandwich")); library(lmtest); library(sandwich)
bptest(model1)
```

- 적합값이 커져도 잔차 폭이 일정해야 함(깔때기 모양이면 위배)
- `bptest()` **p-value가 크면** 등분산 가정 OK

### (3) 자기상관(Serial Correlation) — 잔차들이 서로 독립인가

```r
bgtest(model1)   # Breusch-Godfrey 검정
```

- 잔차가 앞뒤로 상관되면(특히 시계열) 위배임. `bgtest()` p-value가 크면 OK

> 💡 세 검정 모두 **"가정이 만족된다"가 귀무가설**임. 따라서 **p-value가 크면(가정 위배 아님) 오히려 좋은 것**임. 일반 t-검정과 해석 방향이 반대라 헷갈리기 쉬움.

## 3. 모형으로 예측하기

```r
summary(model1)               # 계수 해석
range(adverts$marketing_total)   # 데이터의 X 범위 확인

if(!require("dplyr")) install.packages("dplyr")
suppressMessages(suppressWarnings(library(dplyr)))
dplyr::select(adverts, marketing_total) %>% filter(marketing_total > 430)
```

```r
# marketing_total = 460일 때 매출 예측 + 예측구간
newdata <- data.frame(marketing_total = 460)
predict.lm(model1, newdata, interval = "predict")

# 신뢰수준을 바꿔 가며
predict.lm(model1, newdata, level = 0.99, interval = "predict")
predict.lm(model1, newdata, level = 0.90, interval = "predict")

# 여러 값 한꺼번에
newdata <- data.frame(marketing_total = c(450, 460, 470))
predict.lm(model1, newdata, interval = "predict")
```

- `predict.lm(..., interval = "predict")`: 새 X에 대한 **개별 예측값과 예측구간**을 구함
- `level`로 신뢰수준(90/95/99%)을 조절함. 신뢰수준이 높을수록 구간이 넓어짐

```r
# 표본의 일부로 모형을 세우고 신뢰구간 보기
set.seed(4510)
market_sample <- sample_frac(adverts, 0.30, replace = FALSE)
samp_model <- lm(revenues ~ marketing_total, data = market_sample)
samp_model
confint(samp_model)   # 계수의 신뢰구간
```

> 💡 **예측구간(prediction interval)** 은 개별 관측값이 들어갈 범위라 넓고, **신뢰구간(confidence interval)** 은 평균 반응의 범위라 좁음. 둘을 혼동하지 않도록 함.

## 4. 데이터 정제(가정 위배 다루기)

### 변환(Transformation)으로 가정 맞추기

```r
x0 <- 1:10
y0 <- c(1.00, 1.41, 1.73, 2.00, 2.24, 2.45, 2.65, 2.83, 3.00, 3.16)
fit0 <- lm(y0 ~ x0)

par(mfrow = c(1, 3))
plot(x0, y0, pch = 19, main = "Linearity?"); abline(fit0)
hist(fit0$residuals, main = "Normality?", col = "gray")
plot(fit0$fitted.values, fit0$residuals, main = "Equal Variance?", pch = 19); abline(h = 0)
```

곡선 관계라 가정이 위배됨. Y를 제곱해 보면(`y0`는 사실 √x 형태) 직선이 됨.

```r
y0_t <- y0^2          # 변환
fit0_t <- lm(y0_t ~ x0)
plot(x0, y0_t, pch = 19, main = "Linear"); abline(fit0_t)
hist(fit0_t$residuals, main = "Normal", col = "gray")
plot(fit0_t$fitted.values, fit0_t$residuals, main = "Equal Variance", pch = 19); abline(h = 0)
par(mfrow = c(1, 1))
```

> 💡 관계가 곡선이거나 분산이 불균등할 때 **로그·제곱·제곱근 변환**으로 선형 가정에 맞출 수 있음.

### 이상치(Outlier)와 영향점(Influential Point)

```r
if(!require("MASS")) install.packages("MASS")
suppressMessages(suppressWarnings(library(MASS)))

# 가운데에 있는 이상치 (영향력 큼)
x2 <- 1:20; y2 <- c(1:10, 4, 12:20); fit2 <- lm(y2 ~ x2)
# 끝에 있는 이상치 (직선을 거의 안 바꿈)
x3 <- c(1:20, 30); y3 <- c(0.4, 2.2, 2.2, 5.6, 5.3, 5.2, 7.5, 8.7, 9.6, 9.7, 12.5, 12.4, 12.4, 11.8, 16.1, 16, 17, 18.9, 19.8, 20.6, 30.0)
fit3 <- lm(y3 ~ x3)

par(mfrow = c(1, 2))
plot(x2, y2, pch = 19, main = "Outlier is Influential"); abline(fit2)
plot(x3, y3, pch = 19, main = "Outlier is not Influential"); abline(fit3)
```

> 💡 **이상치(outlier)** 가 모두 위험한 것은 아님. 회귀직선을 크게 바꾸는 점을 특히 **영향점(influential point)** 이라 부름. 이상치는 무작정 지우기보다 영향력을 따져 처리함.

### 실습 — 진단 플롯 4종

```r
x4 <- 1:20
y4 <- c(0.4, 2.2, 2.2, 5.6, 5.3, 5.2, 7.5, 8.7, 9.6, 9.7, 12.5, 12.4, 12.4, 12.8, 16.1, 16.0, 17.0, 11.5, 19.8, 20.6)
fit4 <- lm(y4 ~ x4)
par(mfrow = c(1, 1)); plot(x4, y4, pch = 19, col = "blue"); abline(fit4); summary(fit4)

# 18번째 점(이상치)을 빼고 다시 적합 → 결과 비교
x4_t <- x4[-18]; y4_t <- y4[-18]; fit4_t <- lm(y4_t ~ x4_t); summary(fit4_t)

par(mfrow = c(2, 2)); plot(fit4)   # R 기본 회귀 진단 4종 플롯
```

`plot(모형)`은 잔차-적합값, Q-Q, Scale-Location, 잔차-레버리지의 **진단 플롯 4종**을 자동으로 그려 줌.

## 5. 다중 선형회귀 (Multiple Linear Regression)

```r
# 매출을 세 채널 광고비로 동시에 설명
model2 <- lm(revenues ~ google_adwords + facebook + twitter, data = adverts)
plot(model2)
summary(model2)

# 동일한 가정 진단을 다중회귀에도 적용
library(normtest); jb.norm.test(model2$residuals)   # 정규성
bptest(model2)                                       # 등분산
bgtest(model2)                                       # 자기상관
```

- 설명변수를 `+`로 여러 개 넣으면 다중회귀가 됨
- 각 계수는 **다른 변수를 고정했을 때** 해당 변수가 매출에 주는 효과를 뜻함
- 단순회귀와 **똑같은 가정 진단**을 거쳐야 함

## 핵심 요약

- `lm(Y ~ X)`로 적합하고 `summary()`로 계수·R²·유의성을 읽음
- 결과를 믿기 전에 **정규성(JB)·등분산(BP)·자기상관(BG)** 가정을 진단함 — 세 검정 모두 **p-value가 크면 가정 OK**
- `predict.lm()`으로 예측, **예측구간 ≠ 신뢰구간**
- 가정 위배 시 **변환**으로 대응, **이상치**는 영향력을 보고 판단
- 설명변수를 늘리면 다중회귀, 진단 절차는 동일함
