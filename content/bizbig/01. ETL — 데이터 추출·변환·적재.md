# 01. ETL — 데이터 추출·변환·적재

> 실습 노트북: `MB1_ETL.ipynb` · 데이터: 자전거 대여(bike sharing)

## 이 장에서 배우는 것

**ETL**은 분석의 출발점이 되는 세 단계의 머리글자임.

- **E**xtract(추출): 원천에서 데이터를 읽어옴
- **T**ransform(변환): 분석 목적에 맞게 데이터를 가공·요약함
- **L**oad(적재): 결과를 다른 시스템이나 파일로 내보냄

이 장에서는 `dplyr` 패키지를 이용해 자전거 대여 데이터에서 "비회원이 봄·여름에 만들어낸 매출"을 계절별로 집계하는 작은 분석을 ETL 흐름으로 완성함.

## 1. Extract — 데이터 읽어오기

```r
bike <- read.csv("/content/drive/MyDrive/경영빅데이터분석/ch1/data/Ch1_bike_sharing_data.csv")
str(bike)
```

- `read.csv()`: 쉼표로 구분된 CSV 파일을 데이터프레임으로 읽어옴
- `str()`: 데이터의 **구조(structure)** 를 한눈에 보여줌. 변수 개수, 각 변수의 자료형(int/num/chr/factor), 앞부분 값 몇 개를 출력함

> 💡 데이터를 읽은 직후에는 반드시 `str()`로 **자료형과 변수명을 먼저 확인**하는 습관을 들임. 자전거 데이터는 `datetime, season, holiday, workingday, weather, temp, humidity, casual, registered, count` 등의 열을 가짐. 여기서 `casual`은 비회원, `registered`는 회원 대여 수임.

## 2. Transform — dplyr로 가공하기

`dplyr`는 데이터 가공을 직관적인 **동사(verb)** 로 표현하는 패키지임.

| 동사 | 하는 일 |
|------|---------|
| `filter()` | 조건에 맞는 **행**을 고름 |
| `select()` | 원하는 **열**을 고름 |
| `mutate()` | 새 열을 **계산해 추가**함 |
| `group_by()` | 그룹 기준을 지정함 |
| `summarise()` | 그룹별 **요약값**을 계산함 |

```r
suppressMessages(suppressWarnings(library(dplyr)))
```

`suppressMessages(suppressWarnings(...))`는 패키지를 부를 때 나오는 안내·경고 메시지를 숨겨 출력을 깔끔하게 함.

### 2-1. 행 고르기 — filter()

```r
# 비회원(registered == 0)이면서 봄(1) 또는 여름(2)인 행
extracted_rows <- filter(bike, registered == 0, season == 1 | season == 2)
dim(extracted_rows)
```

- `filter()`에 조건을 **쉼표로 나열하면 AND(그리고)** 로 연결됨
- `|`는 OR(또는)을 뜻함. 따라서 위 조건은 "비회원 **그리고** (봄 **또는** 여름)"임
- `dim()`은 (행 수, 열 수)를 알려 줌

같은 조건을 `%in%`로 더 간결하게 쓸 수 있음.

```r
using_membership <- filter(bike, registered == 0, season %in% c(1, 2))
dim(using_membership)

identical(extracted_rows, using_membership)   # TRUE → 두 결과가 완전히 같음
```

`season %in% c(1, 2)`는 "season이 1 또는 2에 포함되는가?"를 묻는 표현으로, `season == 1 | season == 2`와 동일함. `identical()`이 `TRUE`이면 두 방식의 결과가 똑같다는 뜻임.

### 2-2. 열 고르기 — select()

```r
extracted_columns <- select(extracted_rows, season, casual)
extracted_columns
```

분석에 필요한 `season`(계절)과 `casual`(비회원 대여 수) 두 열만 남김.

### 2-3. 새 열 만들고 그룹 요약 — mutate / group_by / summarise

```r
# 비회원 1건당 5,000원 매출이라고 가정하고 revenue 열 추가
add_revenue <- mutate(extracted_columns, revenue = casual * 5)

# 계절별로 묶어
grouped <- group_by(add_revenue, season)

# 계절별 비회원 수 합계와 매출 합계 계산
report <- summarise(grouped, sum(casual), sum(revenue))
report
```

- `mutate()`로 `revenue = casual * 5`라는 **파생 변수**를 만듦
- `group_by(season)` 후 `summarise()`를 쓰면 **계절별로** 합계가 계산됨
- 결과 `report`는 봄·여름 각각의 비회원 대여 합계와 매출 합계를 담은 작은 요약표임

> 💡 `group_by()` → `summarise()`는 엑셀의 피벗 테이블과 같은 역할임. "어떤 기준으로(group) 무엇을 집계할지(summarise)"를 분리해서 표현하는 것이 핵심임.

## 3. Load — 결과 내보내기

```r
write.csv(report, "/content/drive/MyDrive/경영빅데이터분석/Students/P1691/revenue_report.csv",
          row.names = FALSE)
write.table(report, "/content/drive/MyDrive/경영빅데이터분석/Students/P1691/revenue_report.txt",
            row.names = FALSE, sep = "\t")
```

- `write.csv()`: 결과를 CSV로 저장함
- `write.table(..., sep = "\t")`: 탭으로 구분된 텍스트로 저장함
- `row.names = FALSE`: 불필요한 행 번호 열이 같이 저장되지 않게 함

> ⚠️ 저장 경로의 `P1691` 자리에는 **자신의 학번 폴더**를 만들어 사용함. 공유 드라이브에 그대로 쓰면 다른 사람 결과와 충돌할 수 있음.

## 핵심 요약

- ETL = **Extract(읽기) → Transform(가공) → Load(저장)** 의 한 사이클임
- 데이터를 읽으면 `str()`로 구조부터 확인함
- `dplyr`의 5개 동사(`filter`/`select`/`mutate`/`group_by`/`summarise`)면 대부분의 표 가공이 가능함
- 조건 나열은 AND, `|`는 OR, `%in%`는 포함 여부 판정임

## 연습 문제

1. **회원(`registered`)** 의 가을·겨울 대여를 추출해, 계절별 대여 합계를 구해 보기 (`season %in% c(3, 4)`).
2. 비회원 1건당 매출을 5,000원이 아니라 **6,500원**으로 바꾸면 계절별 매출 합계는 어떻게 달라지는가?
3. `count` 열(전체 대여 수)을 이용해 **날씨(`weather`)별** 평균 대여 수를 `group_by` + `summarise`로 구해 보기.
