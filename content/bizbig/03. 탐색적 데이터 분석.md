# 03. 탐색적 데이터 분석 (EDA)

> 실습 노트북: `MB_3_DK.ipynb` · 데이터: 마케팅(marketing), 자전거 대여(bike)

## 이 장에서 배우는 것

**탐색적 데이터 분석(Exploratory Data Analysis, EDA)** 은 모형을 세우기 전에 데이터를 다양한 각도에서 **요약하고 그려 보며 구조와 관계를 파악**하는 단계임. 이 장에서는 변수 1개·2개·여러 개를 점점 늘려 가며 탐색함.

1. 한 변수 살펴보기 — 표·요약통계
2. 그림이 필요한 이유 — Anscombe의 4중주
3. 두 변수의 관계 — 교차표·상자그림·산점도·상관계수
4. **가성상관(spurious correlation)** 주의
5. 여러 변수 동시 탐색 — `pairs`, `corrgram`

---

marketing <- read.csv("/content/drive/MyDrive/bizbig/ch3/data/Ch3_marketing.csv")

# 인구밀도를 순서 있는 범주로
marketing$pop_density <- factor(marketing$pop_density, ordered = TRUE,

마케팅 데이터는 광고채널별 지출(`google_adwords`, `facebook`, `twitter`), 마케팅 총액(`marketing_total`), 매출(`revenues`), 직원 수(`employees`), 인구밀도(`pop_density`) 등을 담고 있음.

## 1. 한 변수 살펴보기 (Tabular Exploration)

```r
summary(marketing$google_adwords)   # 최소·1사분위·중앙값·평균·3사분위·최대
fivenum(marketing$google_adwords)   # 다섯수치요약(최소·하사분위·중앙·상사분위·최대)

mean(marketing$google_adwords)      # 평균
sd(marketing$google_adwords)        # 표준편차
var(marketing$google_adwords)       # 분산

summary(marketing$pop_density)      # 범주형은 각 범주의 빈도를 보여줌
```

- 숫자형은 **중심(평균·중앙값)** 과 **퍼짐(표준편차·분산)** 을 함께 봄
- 범주형에 `summary()`를 쓰면 범주별 개수를 셈

## 2. 그림이 왜 필요한가 — Anscombe의 4중주

```r
data("anscombe")
anscombe

# 네 쌍(x,y)의 평균·표준편차·분산이 거의 동일함
sapply(anscombe, mean)
sapply(anscombe, sd)
sapply(anscombe, var)
```

`anscombe`는 **요약통계는 거의 같지만 실제 모양은 완전히 다른** 네 쌍의 데이터임.

```r
par(mfrow = c(2, 2))   # 그래프를 2x2로 배치
plot(y1 ~ x1, data = anscombe, type = "p", pch = 16, col = "green"); abline(lm(y1 ~ x1, data = anscombe), col = "red")
plot(y2 ~ x2, data = anscombe, type = "p", pch = 16, col = "green"); abline(lm(y2 ~ x2, data = anscombe), col = "red")
plot(y3 ~ x3, data = anscombe, type = "p", pch = 16, col = "green"); abline(lm(y3 ~ x3, data = anscombe), col = "red")
plot(y4 ~ x4, data = anscombe, type = "p", pch = 16, col = "green"); abline(lm(y4 ~ x4, data = anscombe), col = "red")
```

> 💡 **교훈**: 평균·분산·상관계수 같은 요약값만 믿으면 안 됨. 같은 통계량을 가져도 직선, 곡선, 이상치 하나가 좌우하는 모양 등 전혀 다른 패턴일 수 있음. **반드시 그려서 확인**해야 함.

### 한 변수 시각화

```r
par(mfrow = c(1, 1))
plot(marketing$pop_density)        # 범주형 → 막대그래프

par(mfrow = c(1, 2))
boxplot(marketing$google_adwords, ylab = "Expenditures")   # 상자그림: 분포·이상치
hist(marketing$google_adwords, main = NULL)                # 히스토그램: 분포 모양
```

- **상자그림(boxplot)**: 중앙값·사분위·이상치를 한눈에 보여 줌
- **히스토그램(hist)**: 값의 분포 모양(치우침 등)을 보여 줌

## 3. 두 변수의 관계 (Bivariate Analysis)

변수 두 개의 자료형 조합에 따라 적절한 그림이 다름.

```r
marketing$emp_factor <- cut(marketing$employees, 2)   # 직원 수를 2구간 범주로
summary(marketing)

par(mfrow = c(1, 3))
mosaicplot(table(marketing$pop_density, marketing$emp_factor),
           col = c("gray", "black"), main = "Factor / Factor")   # 범주 vs 범주
boxplot(marketing$marketing_total ~ marketing$pop_density,
        main = "Factor / Numeric")                               # 범주 vs 숫자
plot(marketing$google_adwords, marketing$revenues,
     main = "Numeric / Numeric")                                 # 숫자 vs 숫자
```

| 조합 | 적절한 그림 |
|------|-------------|
| 범주 × 범주 | 모자이크플롯, 교차표(`table`) |
| 범주 × 숫자 | 상자그림(`boxplot`) |
| 숫자 × 숫자 | 산점도(`plot`) |

### 상관계수와 유의성 검정

```r
cor(marketing$google_adwords, marketing$revenues)   # 상관계수(-1 ~ 1)
cor(marketing$google_adwords, marketing$facebook)

cor.test(marketing$google_adwords, marketing$revenues)   # 상관이 통계적으로 유의한가
cor.test(marketing$twitter, marketing$revenues)
cor.test(marketing$facebook, marketing$revenues)
```

- `cor()`: 두 숫자 변수의 **선형 관계 강도**를 -1~1로 나타냄 (0이면 선형관계 없음)
- `cor.test()`: 그 상관이 **우연이 아닌지(유의한지)** p-value로 검정함

## 4. 가성상관(Spurious Correlation) — 함정 주의

```r
# 미국 1인당 모짜렐라 치즈 소비량 vs 토목공학 박사 학위 수
cheese  <- c(9.3, 9.7, 9.7, 9.7, 9.9, 10.2, 10.5, 11, 10.6, 10.6)
degrees <- c(480, 501, 540, 552, 547, 622, 655, 701, 712, 708)
cor(cheese, degrees)        # 매우 높게 나옴!
cor.test(cheese, degrees)
```

치즈 소비량과 박사 학위 수는 **인과관계가 없는데도** 상관계수가 매우 높게 나옴. 둘 다 시간에 따라 같이 증가하는 추세를 가졌기 때문임. 이것이 **가성상관**임.

```r
install.packages("tseries"); library(tseries)

# 1단계: 각 시계열이 비정상(추세 보유)인지 ADF 검정
adf.test(cheese)
adf.test(degrees)

# 2단계: 회귀 후 잔차 추출
model <- lm(degrees ~ cheese)
summary(model)

# 3단계: 잔차에 ADF 검정 → 가성상관 판단의 핵심
adf.test(model$residuals)

# 4단계: 잔차 시각화 (한쪽으로 흐르면 가성상관 의심)
plot(model$residuals, type = "l", col = "red",
     main = "잔차 추이", ylab = "잔차", xlab = "시간")
abline(h = 0, lty = 2, col = "gray")
```

> 💡 **상관 ≠ 인과**. 두 변수가 함께 추세를 가지면 가짜 상관이 나타날 수 있음. `adf.test()`(단위근/정상성 검정)로 회귀 **잔차가 정상적인지** 확인하는 것이 한 가지 판별법임. 잔차가 한쪽으로 흐르면 가성상관을 의심함.

## 5. 여러 변수 동시 탐색 (Multivariate)

```r
summary(marketing)
pairs(marketing)            # 모든 변수 쌍의 산점도 행렬
cor(marketing[, 1:6])       # 숫자 변수들의 상관행렬

if(!require("psych")) install.packages("psych")
suppressMessages(suppressWarnings(library(psych)))
corr.test(marketing[, 1:6]) # 상관계수 + 유의성을 한 번에
```

- `pairs()`: 변수 쌍마다 산점도를 그려 **한눈에 관계 패턴**을 봄
- `cor(df)`: 여러 변수의 **상관행렬**을 만듦
- `corr.test()`: 상관계수와 p-value를 함께 줌

### 상관도(Correlogram)

```r
options(warn = -1)
if(!require("corrgram")) install.packages("corrgram")
suppressMessages(suppressWarnings(library(corrgram)))

corrgram(marketing[, 1:6], order = TRUE,
         main = "Correlogram (Unordered panels)",
         lower.panel = panel.conf, upper.panel = panel.ellipse,
         diag.panel = panel.minmax, text.panel = panel.txt)

corrgram(marketing[, 1:6], order = TRUE,
         main = "Correlogram (Ordered)",
         lower.panel = panel.shade, upper.panel = panel.pie,
         diag.panel = panel.minmax, text.panel = panel.txt)
```

`corrgram`은 상관행렬을 **색·타원·파이 모양**으로 시각화해 강한 상관 쌍을 직관적으로 찾게 해 줌.

## 6. 실습 — 자전거 데이터에 적용

```r
bike <- read.csv("/content/drive/MyDrive/bizbig/ch3/data/Ch2_clean_bike_sharing_data.csv",
                 stringsAsFactors = TRUE)

bike$season  <- factor(bike$season, ordered = TRUE,
                       levels = c("spring", "summer", "fall", "winter"))
bike$weather <- factor(bike$weather, ordered = TRUE,
                       levels = c("clr_part_cloud", "mist_cloudy", "lt_rain_snow", "hvy_rain_snow"))

if(!require("lubridate")) install.packages("lubridate")
suppressMessages(suppressWarnings(library(lubridate)))
bike$datetime <- ymd_hms(bike$datetime)
```

2장에서 정제·저장한 데이터를 다시 불러와 EDA 기법을 그대로 적용함.

```r
str(bike)                 # Q1. 구조 확인
table(bike$season)        # Q2. 계절별 관측 수
mean(bike$temp); sd(bike$temp)   # Q3. 기온 평균·표준편차
hist(bike$temp)           # Q4. 기온 분포
plot(bike$workingday); hist(bike$casual)   # Q5. 근무일 분포, 비회원 분포

nbike <- bike[, -c(1:5, 13)]   # Q6. 숫자형 열만 남겨 상관 분석
cor(nbike)

corr.test(nbike)
corrgram(nbike, order = TRUE, main = "Correlogram of Bike Data",
         lower.panel = panel.shade, upper.panel = panel.pie,
         diag.panel = panel.minmax, text.panel = panel.txt)
```

`bike[, -c(1:5, 13)]`처럼 **음수 인덱스**를 쓰면 해당 열을 **제외**함. 여기서는 날짜·범주형 등을 빼고 숫자형만 남겨 상관을 분석함.

## 핵심 요약

- EDA는 **요약통계 + 시각화**로 데이터를 이해하는 단계임
- Anscombe 4중주: 요약값이 같아도 모양은 다름 → **반드시 그려 봄**
- 두 변수 관계는 자료형 조합에 맞는 그림을 고름(모자이크/상자/산점도)
- **상관은 인과가 아님**. 추세를 공유하면 가성상관이 생김(`adf.test`로 점검)
- `pairs`, `cor`, `corrgram`으로 여러 변수를 한눈에 탐색함
