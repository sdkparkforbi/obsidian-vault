# 05. 시계열 분석 (Time Series Analysis)

> 실습 노트북: `Ch6_TimeSeries_Analysis.ipynb` · 데이터: 항공 승객(airpass), 자전거 대여(ridership)

## 이 장에서 배우는 것

**시계열(time series)** 은 시간 순서대로 관측된 데이터임(월별 승객 수, 일별 매출 등). 일반 데이터와 달리 **추세·계절성·시간 의존성**을 가지므로 전용 기법이 필요함. 이 장에서는 다음을 다룸.

1. 선형회귀로 추세 보기 (그리고 그 한계)
2. 시계열 분해(추세·계절성·불규칙)
3. 차분(differencing)으로 정상성 확보
4. ACF/PACF로 ARIMA 차수 식별
5. ARIMA·auto.arima·TBATS로 예측

> ⚠️ **실행 전 준비**: Colab 런타임을 **R**로 설정함. ARIMA 실습용 `Ch6_ridership_data_2011-2012.csv`는 왼쪽 파일 탐색기(📁)로 업로드함.

## 1. 환경 설정과 데이터 탐색

```r
# TSA 패키지(시계열 + airpass 예제 데이터) 설치
if (!require("remotes")) install.packages("remotes"); library(remotes)
if (!require("locfit"))  remotes::install_version("locfit", "1.5.9.2"); library(locfit)
if (!require("TSA"))     install.packages("TSA"); library(TSA)

data(airpass)
str(airpass)      # ts 객체, 주기 12 = 월별
summary(airpass)
```

`airpass`는 1949~1960년 **월별 국제선 항공 승객 수** 시계열임. `ts` 객체는 일반 벡터와 달리 시작 시점·주기 정보를 함께 가짐.

```r
# 회귀에 쓰기 위해 (승객수, 시간) 데이터프레임으로 변환
volume <- as.matrix(airpass)
time   <- as.matrix(time(airpass))
airpass_df <- as.data.frame(cbind(volume, time))
colnames(airpass_df) <- c("volume", "time")
head(airpass_df)
```

`time(airpass)`는 각 관측값에 대응하는 시간(연도 소수점)을 뽑아 줌.

## 2. 선형회귀로 추세 보기 (그리고 한계)

```r
lmfit <- lm(volume ~ time, data = airpass_df)   # volume = β0 + β1·time
summary(lmfit)
```

시간을 설명변수로 하는 회귀로 **장기 추세**를 직선으로 근사함.

```r
par(mfrow = c(1, 3))
plot(airpass_df$time, airpass_df$volume, pch = 19, main = "Linearity?"); abline(lmfit)
hist(lmfit$residuals, main = "Normality?", col = "gray")
plot(lmfit$fitted.values, lmfit$residuals, main = "Equal Variance?", pch = 19); abline(h = 0)
par(mfrow = c(1, 1))
```

> 💡 항공 승객 데이터는 시간이 갈수록 변동 폭이 커져 **등분산 가정이 위배**됨. 또한 계절성·시간 의존성 때문에 단순 회귀로는 부족함 → 시계열 전용 기법이 필요한 이유임.

### 예측구간과 신뢰구간

```r
plot(airpass, main = "95% Confidence & Prediction Intervals")
abline(lmfit, col = "blue")

newdata <- data.frame(time = seq(1960, 1972, 2))
pred <- predict.lm(lmfit, newdata, interval = "predict")     # 예측구간(넓음)
points(seq(1960, 1972, 2), pred[, 1], pch = 19, col = "blue")
abline(lsfit(seq(1960, 1972, 2), pred[, 2]), col = "red")
abline(lsfit(seq(1960, 1972, 2), pred[, 3]), col = "red")

pred <- predict.lm(lmfit, newdata, interval = "confidence")  # 신뢰구간(좁음)
abline(lsfit(seq(1960, 1972, 2), pred[, 2]), lty = 2, col = "red")
abline(lsfit(seq(1960, 1972, 2), pred[, 3]), lty = 2, col = "red")

rm(airpass_df, newdata, pred, time, volume, lmfit)   # 임시 객체 정리
```

빨강 실선이 예측구간(넓음), 점선이 신뢰구간(좁음)임. ([[04. 선형회귀]]의 개념과 동일함)

## 3. 시계열 분해 (Decomposition)

```r
if (!require("forecast")) install.packages("forecast"); library(forecast)
plot(decompose(airpass))
```

`decompose()`는 시계열을 네 성분으로 나눔.

| 성분 | 의미 |
|------|------|
| **observed** | 원본 데이터 |
| **trend** | 장기 추세 |
| **seasonal** | 주기적으로 반복되는 계절성 |
| **random** | 위 둘로 설명 안 되는 불규칙 성분 |

> 💡 분해를 보면 데이터에 **상승 추세**와 **연 단위 계절성**이 모두 있음이 한눈에 드러남.

---

## 4. 차분(Differencing)으로 정상성 확보

ARIMA 같은 모형은 **정상 시계열(stationary, 추세·계절성이 없는 상태)** 을 전제로 함. **차분**은 이를 만드는 핵심 도구임.

```r
# 추세 + 계절성을 가진 가상 시계열로 차분 효과 시연
seq_down <- seq(.625, .125, -0.125); seq_up <- seq(0, 1.5, 0.25)
y <- c(seq_down, seq_up, seq_down + .75, seq_up + .75, seq_down + 1.5, seq_up + 1.5)

par(mfrow = c(1, 3))
plot(y, type = "b", ylim = c(-.1, 3))                            # 원본
plot(diff(y), ylim = c(-.1, 3), xlim = c(0, 36))                 # 1차 차분 → 추세 제거
plot(diff(diff(y), lag = 12), ylim = c(-.1, 3), xlim = c(0, 36)) # +계절 차분 → 계절성 제거
par(mfrow = c(1, 1))

detach(package:TSA, unload = TRUE)   # TSA와 forecast의 함수 충돌 방지
rm(y, seq_down, seq_up)
```

- `diff(y)`: **1차 차분**(이웃한 값의 차이) → 추세를 제거함
- `diff(..., lag = 12)`: **계절 차분**(12개월 전과의 차이) → 계절성을 제거함
- 두 차분을 합치면 시계열이 정상성에 가까워짐

## 5. ARIMA 모델링 — 자전거 대여 데이터

### 데이터 준비와 월별 집계

```r
# 업로드한 CSV를 (어느 폴더에 있든) 자동으로 찾아 읽기
candidate_paths <- c("./data/Ch6_ridership_data_2011-2012.csv",
                     "Ch6_ridership_data_2011-2012.csv",
                     "/content/Ch6_ridership_data_2011-2012.csv")
csv_path <- candidate_paths[file.exists(candidate_paths)][1]
if (is.na(csv_path)) stop("CSV 파일을 찾을 수 없습니다. 파일을 업로드하세요.")
cycle <- read.csv(csv_path); head(cycle)
```

```r
# 시간 단위 기록을 연·월별 합계로 집계
if (!require("dplyr"))     install.packages("dplyr"); library(dplyr)
if (!require("lubridate")) install.packages("lubridate"); library(lubridate)

monthly_ride <- as.data.frame(cycle %>%
  group_by(year = year(datetime), month = month(datetime)) %>%
  summarise(riders = sum(count), .groups = "drop"))
table(monthly_ride$year, monthly_ride$month)   # 빠진 달이 없는지 확인
```

```r
# 월별 시계열(ts) 객체 생성 — 2011년 1월 시작, 주기 12
riders  <- monthly_ride[, 3]
monthly <- ts(riders, frequency = 12, start = c(2011, 1))
monthly
```

### 분해와 차분으로 차수 가늠

```r
plot(decompose(monthly))   # 추세·계절성 확인

par(mfrow = c(1, 3))
plot(monthly, ylim = c(-30000, max(monthly)))                       # 원본
plot(diff(monthly), ylim = c(-30000, max(monthly)))                 # 1차 차분
plot(diff(diff(monthly), lag = 12), ylim = c(-30000, max(monthly))) # +계절 차분
par(mfrow = c(1, 1))
```

### ACF / PACF로 모형 차수 식별

```r
par(mfrow = c(1, 2))
acf(monthly,  xlim = c(0, 2))   # 자기상관함수 → MA 차수(q) 단서
pacf(monthly, xlim = c(0, 2))   # 편자기상관함수 → AR 차수(p) 단서
par(mfrow = c(1, 1))
```

> 💡 **ARIMA(p, d, q)** 에서 `p`=AR(자기회귀) 차수, `d`=차분 횟수, `q`=MA(이동평균) 차수임. ACF는 q, PACF는 p를 고르는 단서를 줌.

### 후보 모형 적합과 진단

```r
fit1 <- Arima(monthly, c(1, 0, 0), seasonal = list(order = c(0, 0, 0))); fit1; tsdiag(fit1)  # AR(1)
fit2 <- Arima(monthly, c(1, 1, 0), seasonal = list(order = c(0, 0, 0))); fit2; tsdiag(fit2)  # AR(1)+1차차분
fit3 <- Arima(monthly, c(2, 1, 0), seasonal = list(order = c(0, 0, 0))); fit3; tsdiag(fit3)  # AR(2)+1차차분
fit4 <- Arima(monthly, c(1, 1, 0), seasonal = list(order = c(0, 1, 0))); fit4; tsdiag(fit4)  # +계절차분
fit5 <- Arima(monthly, c(0, 1, 1), seasonal = list(order = c(0, 0, 0))); fit5; tsdiag(fit5)  # MA(1)+1차차분
```

- `Arima(데이터, c(p, d, q), seasonal = list(order = c(P, D, Q)))`로 모형을 적합함
- `tsdiag()`는 잔차 진단 플롯을 그림. **잔차에 자기상관이 남지 않고 AIC가 작은** 모형이 좋음
- 여러 후보의 AIC와 잔차를 비교해 가장 적절한 것을 고름

### 예측

```r
yr_forecast <- forecast(fit2, h = 12)   # fit2로 향후 12개월 예측
plot(yr_forecast)                       # 예측값 + 신뢰구간 음영
```

### 자동 모형 선택 (auto.arima)

```r
fit6 <- auto.arima(monthly)   # AIC 기준 최적 차수 자동 탐색
fit6; tsdiag(fit6)
mm_forecast <- forecast(fit6, h = 12); plot(mm_forecast)

# 추정 계수의 유의성 (z-검정)
(z <- fit6$coef / sqrt(diag(fit6$var.coef)))      # z = 계수 / 표준오차
(pvalue <- 2 * (1 - pnorm(abs(z))))               # 양측검정 p-value
```

`auto.arima()`는 차수를 자동으로 탐색해 줌. 다만 결과를 맹신하지 말고 `tsdiag()`로 잔차를, z-검정으로 계수 유의성을 직접 확인함.

## 6. 고급 모형 TBATS와 결과 정리

```r
monthly_data  <- tbats(monthly)                  # 복잡한 계절성·추세 자동 처리
year_forecast <- forecast(monthly_data, h = 12)
plot(year_forecast)

summary(year_forecast$mean)    # 예측 평균
summary(year_forecast$upper)   # 예측 상한
summary(year_forecast$lower)   # 예측 하한
```

```r
# 연도별 평균 대여량 (2011·2012 실제, 2013 예측)
(mean_2011 <- round(as.numeric(filter(monthly_ride, year == 2011) %>% summarise(mean = mean(riders))), 0))
(mean_2012 <- round(as.numeric(filter(monthly_ride, year == 2012) %>% summarise(mean = mean(riders))), 0))
(mean_2013 <- round(mean(year_forecast$mean), 0))
(max_mean_2013 <- round(max(year_forecast$mean), 0))
```

`(변수 <- 값)`처럼 괄호로 감싼 할당문은 **값을 저장하면서 동시에 출력**함.

```r
# 예측 그래프 위에 연도별 평균선·라벨 겹쳐 그리기
plot(year_forecast)
abline(h = max(year_forecast$mean), lty = 2, col = "blue")
segments(2011, mean_2011, 2012, mean_2011, col = "darkgray", lty = 2, lwd = 2)
segments(2012, mean_2012, 2013, mean_2012, col = "darkgray", lty = 2, lwd = 2)
segments(2013, mean_2013, 2014, mean_2013, col = "blue", lty = 2, lwd = 2)
text(2011.15, mean_2011 + 10000, mean_2011)
text(2012,    mean_2012 + 10000, mean_2012)
text(2013,    mean_2013 + 10000, mean_2013)
text(2013.85, max_mean_2013 + 10000, max_mean_2013)
```

> ⚠️ Colab은 셀마다 그래프를 새로 그리므로, `plot(year_forecast)` 와 라벨 추가 코드를 **하나의 셀로 합쳐** 실행해야 평균선이 예측 그래프 위에 제대로 겹쳐짐.

## 핵심 요약

- 시계열은 **추세·계절성·시간 의존성**을 가져 일반 회귀로는 부족함
- `decompose()`로 추세·계절성·불규칙을 분리해 구조를 파악함
- **차분**으로 정상성을 확보하고, **ACF/PACF**로 ARIMA(p,d,q) 차수를 식별함
- `Arima()`로 후보를 적합하고 `tsdiag()`·AIC로 비교, `forecast()`로 예측함
- `auto.arima()`·`tbats()`로 자동·고급 모델링이 가능하나, **잔차·계수 진단은 직접** 확인함
