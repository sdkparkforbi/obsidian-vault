# 02. 데이터 정제 (Data Cleansing)

> 실습 노트북: `MB2_Data_Cleansing.ipynb` · 데이터: 자전거 대여 원시 데이터(raw)

## 이 장에서 배우는 것

현실의 데이터에는 거의 항상 **결측치(빈 값), 오류값(잘못 입력된 값), 표기가 제각각인 문자열**이 섞여 있음. 이런 데이터를 그대로 분석하면 결과가 왜곡되므로, 분석 전에 **정제(cleansing)** 가 반드시 필요함. 이 장에서는 다음을 다룸.

1. 결측치(NA) 찾기
2. 오류값 찾아 고치기
3. 분석에 맞는 **자료형으로 변환**하기
4. 날짜·시간 변환
5. 문자열을 **표준 형식으로 통일**하기

문자열 처리는 `stringr`, 날짜 처리는 `lubridate` 패키지를 사용함.

---

## 0. 데이터 읽기

```r
bike <- read.csv("/content/drive/MyDrive/bizbig/ch2/data/Ch2_raw_bikeshare_data.csv")
str(bike)
```

`str()`로 보면 1장과 달리 이 파일은 **정제 전 원시 데이터**라서, 숫자여야 할 `humidity`가 문자(chr)로 읽히거나 `sources` 열에 빈 값이 섞여 있는 등 문제가 보임.

---

## 1. 결측치(Missing Values) 찾기

```r
# 전체 데이터에 NA가 몇 개인지
table(is.na(bike))

if(!require("stringr")) install.packages("stringr")
suppressMessages(suppressWarnings(library(stringr)))

# sources 열에 'NA'라는 글자(문자열)가 들어 있는지 탐지
str_detect(bike$sources, "NA")

# sources 열에 실제 결측치(R의 NA)가 있는지
table(is.na(bike$sources))
```

- `is.na(x)`: 각 값이 결측치이면 `TRUE`. `table()`로 감싸면 `TRUE/FALSE` 개수를 셈
- `if(!require("pkg")) install.packages("pkg")`: 패키지가 없을 때만 설치하는 관용구임
- ⚠️ **글자 "NA"(문자열)** 와 **진짜 결측치 `NA`(R의 결측 표시)** 는 다름. `str_detect(..., "NA")`는 글자를 찾고, `is.na()`는 진짜 결측을 찾음. 둘을 구분하는 것이 정제의 첫걸음임

---

## 2. 오류값(Erroneous Values) 찾아 고치기

```r
# humidity(습도)는 숫자여야 하는데, 알파벳이 섞인 값을 찾음
bad_data <- str_subset(bike$humidity, "[a-z A-Z]")
location <- str_detect(bike$humidity, bad_data)
bike[location, ]
```

- `[a-z A-Z]`는 **정규표현식**으로 "영문 소문자 또는 대문자 또는 공백"을 뜻함
- `str_subset()`은 그 패턴이 들어간 **값 자체**를 돌려주고, `str_detect()`는 각 행이 해당하는지 `TRUE/FALSE`를 돌려줌
- `bike[location, ]`로 문제 있는 행을 직접 눈으로 확인함

```r
# 잘못된 값을 올바른 값(예: 61)으로 교체
bike$humidity <- str_replace_all(bike$humidity, bad_data, "61")
bike[location, ]
```

`str_replace_all()`로 오류값을 정상값으로 바꿈. 무엇으로 바꿀지는 도메인 지식(주변 값, 평균 등)으로 판단함.

---

## 3. 자료형 변환(Type Conversion)

분석 함수들은 변수의 **자료형**에 따라 다르게 동작하므로, 각 변수를 적절한 형으로 바꿔 줘야 함.

```r
# 문자 → 숫자
bike$humidity <- as.numeric(bike$humidity)

# 숫자 코드 → 범주형 factor (의미 있는 라벨 부여)
bike$holiday <- factor(bike$holiday, levels = c(0, 1),
                       labels = c("no", "yes"))
bike$workingday <- factor(bike$workingday, levels = c(0, 1),
                          labels = c("no", "yes"))

# 순서가 있는 범주형 (ordered factor)
bike$season <- factor(bike$season, levels = c(1, 2, 3, 4),
                      labels = c("spring", "summer", "fall", "winter"),
                      ordered = TRUE)

bike$weather <- factor(bike$weather, levels = c(1, 2, 3, 4),
                       labels = c("clr_part_cloud", "mist_cloudy",
                                  "lt_rain_snow", "hvy_rain_snow"),
                       ordered = TRUE)
str(bike)
```

- `as.numeric()`: 문자형을 숫자형으로 바꿈
- `factor()`: 숫자 코드(0/1, 1~4)를 **사람이 읽을 수 있는 범주**로 바꿈
  - `levels`는 원래 값, `labels`는 붙일 이름
  - `ordered = TRUE`는 **순서가 있는 범주**(봄<여름<가을<겨울, 날씨의 좋고 나쁨)임을 표시함

> 💡 `holiday`나 `season`을 숫자(0/1, 1~4)로 두면 평균을 내는 등 의미 없는 계산이 가능해짐. factor로 바꾸면 R이 이를 **범주**로 올바르게 다룸.

### 날짜·시간 변환

```r
if(!require("lubridate")) install.packages("lubridate")
suppressMessages(suppressWarnings(library(lubridate)))
bike$datetime <- mdy_hm(bike$datetime)
str(bike)
```

`lubridate`는 날짜 변환을 **글자 순서대로 함수 이름을 고르는** 방식으로 매우 쉽게 해 줌.
- `mdy_hm`: 원본이 **월(m)-일(d)-년(y) 시(h):분(m)** 순서일 때 사용함
- 원본 형식에 맞춰 `ymd()`, `dmy()`, `ymd_hms()` 등을 골라 씀

## 4. 문자열 표준화(String Standardization)

같은 의미인데 표기가 다른 값(`Google`, `google`, ` google `, `www.google.com`)을 하나로 통일함.

```r
unique(bike$sources)        # 현재 어떤 값들이 있는지 확인
bike$sources <- tolower(bike$sources)   # 모두 소문자로
```

```r
# 앞뒤 공백 제거 후, 비어 있는 값은 'unknown'으로
bike$sources <- str_trim(bike$sources)
na_loc <- is.na(bike$sources)
bike$sources[na_loc] <- "unknown"
unique(bike$sources)
```

- `tolower()`: 대소문자를 소문자로 통일함
- `str_trim()`: 문자열 앞뒤의 공백을 제거함
- 결측치는 `"unknown"`이라는 명시적 범주로 채움

```r
# 'www.무엇.무엇' 형태의 웹주소를 모두 'web'으로 통일
web_sites <- "(www.[a-z]*.[a-z]*)"
bike$sources <- str_replace_all(bike$sources, web_sites, "web")
unique(bike$sources)
```

여러 형태의 웹주소를 정규표현식 하나로 묶어 `"web"` 한 범주로 정리함. 노트북의 주석 *"The power of seven, plus or minus two"* 는 사람이 한 번에 기억할 수 있는 범주 수(7±2)를 넘지 않게 **범주를 적절히 묶으라**는 뜻임.

```r
bike$sources <- as.factor(bike$sources)   # 정리된 문자열을 범주형으로
str(bike)   # 분석 준비 완료된 데이터 구조 확인
```

## 핵심 요약

| 문제 | 진단 함수 | 처리 함수 |
|------|-----------|-----------|
| 결측치 | `is.na()`, `table()` | 값 대입(`"unknown"`, 평균 등) |
