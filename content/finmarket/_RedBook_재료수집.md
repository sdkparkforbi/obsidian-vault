# Red Book 재료 수집 (작업용)

> Yellow Book(D 매뉴얼) 상품별 검토 중 **Red Book(해설서)로 보낼 재료**를 모으는 작업 노트.
> Red Book = Yellow Book 해설서 + 학생 조사 상세 + 실제 사례/시점성 데이터.
> **정체성: 실무 활용형 핸드북** — 절차·증권사 비교·실제 사례·체크리스트 등 현장에서 바로 쓰는 실무 지식 중심 (Yellow=무엇인가/이론, Red=실제로 어떻게/실무).
> 검토 기준: ① 시장성 수치·실제 종목 예시 ② 학생 자료에만 있는 추가 디테일 ③ 검증 필요 사항.
