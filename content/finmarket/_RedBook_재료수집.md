# Red Book 재료 수집 (작업용)

> Yellow Book(D 매뉴얼) 상품별 검토 중 **Red Book(해설서)로 보낼 재료**를 모으는 작업 노트.
> Red Book = Yellow Book 해설서 + 학생 조사 상세 + 실제 사례/시점성 데이터.
> **정체성: 실무 활용형 핸드북** — 절차·증권사 비교·실제 사례·체크리스트 등 현장에서 바로 쓰는 실무 지식 중심 (Yellow=무엇인가/이론, Red=실제로 어떻게/실무).
> 검토 기준: ① 시장성 수치·실제 종목 예시 ② 학생 자료에만 있는 추가 디테일 ③ 검증 필요 사항.

## 07. 우선주
- **실제 상장 우선주 예시** 수록 필요: 삼성전자우·현대차우·LG화학우·한화우·금융지주 우선주 등 (현재 배당수익률 시점 박아 정리)
- **검증 필요**: "통신 우선주" 국내 상장 여부 — SKT·KT·LGU+ 우선주 미상장 추정. Red Book에서 사실 확인 후 수록/삭제
- Yellow에서 이관됨: 배당수익률 구체 수치(금융지주 5~7%/통신 4~6%) → 시점성 데이터로 Red에 재배치
- 학생(임대섭) 보고서: 매뉴얼과 거의 동일, 추가 디테일 적음

## 08. 해외주식
- **학생(홍성혁) 자료가 매뉴얼보다 풍부** → Red Book 핵심 재료:
  - 시장별 거래시간·결제일 표(미국·일본 T+3·홍콩·베트남·독일 Xetra)
  - 시장별 장기수익률 표(S&P500·나스닥100·Nikkei·SENSEX·VN-Index·CSI300) — 시점 데이터
  - DR(ADR/GDR) 설명, 환헤지 전략(환헤지 ETF(H)·달러 적립식 환전)
  - 정보 비대칭 리스크·시차 리스크, 서학개미 현상, 금투세 폐지(2025) 이슈
  - 국가별 외국인 투자 제한(중국 후강퉁·선강퉁 한도, 신흥국 섹터 제한)
  - 참고문헌 18건(법령·기관·논문) — Red Book 출처로 활용
- Yellow에서 이관됨: S&P500 +13~14%, 나스닥100 +35% 등 지수 수익률 → 시점성 데이터로 Red에 재배치
- ⚠️ 학생 오류 주의: 미국 결제일 "T+2"로 표기(틀림). 정답 T+1(2024.5). Red Book에 끌어오지 말 것

## 09. 공매도 (★ Red Book 최우선 소스 — 지소윤 621줄 상품설명서)
- 6개 증권사 비교(미래에셋·키움·삼성·NH·KB·한투): 담보유지비율(대주전용 105%·일반신용 140%·미래에셋 120%), 차입수수료(한국증권금융 A군 2.5%·B군 4.0%), 투자한도 3단계(3,000만/7,000만/무제한)
- 진입 절차: 사전교육(금융투자교육원 40분)·모의거래(KRX strn.krx.co.kr)·신용약정·위험고지
- 매매 규칙: 업틱룰(직전가 이하 매도 금지), 현금/현물상환, 담보부족→익익영업일 자동 반대매매, NXT 프리·애프터마켓 공매도 금지
- **실제 사례**: 2023 에코프로 숏스퀴즈(평균진입가 대비 64% 평가손실)·2021 게임스탑, 재개시점별 코스피 수익률(2009/2011/2021)
- 구조: 4단 차입(실질보유자 연기금·운용사→한국증권금융 중앙풀→증권사→개인), 무차입 금지(부당이득 4~6배 벌금)
- 세제비교: 인버스ETF/ETN(배당세 15.4%)·해외인버스(양도세 22%)·ELW/풋옵션(파생양도세 11%) vs 공매도(일반주식과 동일)
- 자가진단 5문항·통합 안전 체크리스트(부록)
- ※ "분류 밖 서비스 - 거래 행위형"에도 해당 → 이중 활용 가능
- Yellow 정밀화 후보: D 차입수수료 "연 1~5%" → 한국증권금융 등급별(2.5%/4%)로 정밀화 검토

## 10. 콜 (이서희)
- 콜금리 = **통화정책 전달경로** — 한국은행 기준금리 결정 → 콜금리 형성 → 시장 파급
- 자금중개 3사 역할 상세: 한국자금중개(콜·RP 핵심), 서울외국환중개(외환연계), KIDB(채권·단기)
- 거래 절차 4단계: 호가제출 → 매칭 → BOK-Wire+ 당일 결제 → 익일물 만기상환
- 위험 4종: 신용·유동성·금리·시스템 / 실제 사례 2008 글로벌위기·2011 유럽위기 콜금리 급등
- 규제 동향: MMF 콜 편입비중 규제, LCR(바젤III), 참여기관 다변화(증권사 직접참여), BOK-Wire+ 고도화
- Yellow에서 이관: 콜금리 "1% 이하~2%대"(저금리기 낡은 값) → Red에 시점별 콜금리 추이로 수록 가능
