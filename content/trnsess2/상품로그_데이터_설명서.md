# 📋 상품로그(goods_log) 데이터 설명서

## 1. 개요

상품로그는 **고객이 상품을 조회한 행동 기록**임

| 항목 | 내용 |
|:---|:---|
| 기록 단위 | 고객이 상품 하나를 조회할 때마다 1건 |
| 기록 내용 | 누가, 어떤 상품을, 어떤 경로로 봤는가 |
| 데이터 기간 | 2025년 8월 ~ 9월 |
| 분석 대상 | 5회 이상 조회 고객 23,116명, 713,255건 |

---

## 2. 필드 구조

### 2.1 고객 정보

| 필드명 | 설명 | 예시 |
|:---|:---|:---|
| customer_id_encoded | 고객 고유 ID (암호화) | ZoItzKtXOKDsc+fHR77SVQAA== |

### 2.2 상품 정보

| 필드명 | 설명 | 예시 |
|:---|:---|:---|
| product_code | 상품코드 | 14337391 |
| product_name | 상품명 | 리얼백 BBAC 패션 잡화 소품 키홀더 |

### 2.3 카테고리 정보 (4단계 계층)

```
category_l (대분류) → category_m (중분류) → category_s (소분류) → category_d (세분류)
     31개                 16개                  25개                  23개
```

| 필드명 | 설명 | 예시 |
|:---|:---|:---|
| category_l / category_l_name | 대분류 | 20 / 패션잡화/보석 |
| category_m / category_m_name | 중분류 | 2 / 시즌/패션소품 |
| category_s / category_s_name | 소분류 | 1 / 기타패션소품 |
| category_d / category_d_name | 세분류 | 5 / ... |

> 상세 분포는 [[상품로그_코드집#대분류 코드표]] 참조

### 2.4 진입 경로 정보 (3단계)

고객이 상품 페이지에 도달한 경로를 3단계로 기록함

```
entry_code ────→ click_code ────→ page_code
(진입 방식)       (클릭 위치)       (페이지 ID)
 필수(100%)       선택(30%)        선택(14%)
```

| 필드명 | 설명 | 결측률 | 상세 |
|:---|:---|:---:|:---|
| entry_code | 진입 방식 (어떻게 들어왔나) | 0% | [[상품로그_코드집#진입타입코드 (entry_code)]] |
| click_code | 클릭 위치 (어디를 클릭했나) | 70% | [[상품로그_코드집#진입소스코드 (click_code)]] |
| page_code | 페이지 ID (어떤 페이지 경유) | 86% | [[상품로그_코드집#진입페이지ID (page_code)]] |

> ⚠️ **결측 해석**: click_code/page_code 결측은 "정보 없음"이 아니라 "해당 경로 없음" (기본 진입 시 정상)

### 2.5 채널 정보

| 필드명 | 설명 | 상세 |
|:---|:---|:---|
| order_channel_code / order_channel_name | 접속 기기 (어떤 기기로) | [[상품로그_코드집#주문매체코드 (order_channel_code)]] |
| ad_channel_code / ad_channel_name | 유입 경로 (어떤 광고로) | [[상품로그_코드집#광고매체 (ad_channel)]] |

## 5. MBTI 지표 활용 가이드

| 차원 | 활용 필드 | 지표 예시 |
|:---|:---|:---|
| **J/P** | entry_code, click_code | 검색 진입 비율, 베스트 이용률, 카테고리 진입률 |
| **S/N** | category_*, click_code | 카테고리 집중도, 기획전/이벤트 비율 |
| **T/F** | click_code (DEAL, AREA) | 딜 페이지 비율, 추천 클릭률 |
| **E/I** | order_channel, 로그 수 | 채널 다양성, 활동량 |

### 주의사항

1. **결측 처리**: click_code/page_code 결측은 "기본 진입"으로 해석
2. **비율 계산**: 결측 포함 전체 대비 비율로 계산
3. **최소 로그 수**: 5회 이상 조회 고객만 분석 대상
