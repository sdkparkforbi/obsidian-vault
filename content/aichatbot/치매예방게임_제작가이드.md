# 치매예방 게임 제작 가이드

## 📋 프로젝트 개요

어르신들을 위한 인터랙티브 치매예방 게임 모음
- 한국 전통 놀이 기반 6가지 두뇌 훈련 게임
- MySQL 데이터베이스 연동으로 점수 저장
- PHP 백엔드 API

---

## 🎮 게임 구성

| 게임 | 설명 | 두뇌 훈련 효과 |
|------|------|---------------|
| 🎴 화투 짝맞추기 | 뒤집어진 화투 패의 짝 찾기 | 단기 기억력 |
| 🎯 윷놀이 | 윷을 던져 도착점까지 이동 | 판단력 |
| 🔢 숫자 기억하기 | 화면에 나타난 숫자 순서대로 입력 | 작업 기억력 |
| 📜 속담 완성하기 | 한국 전통 속담의 빈 칸 채우기 | 언어능력, 장기기억 |
| 🧮 산수 계산 | 간단한 덧셈/뺄셈 문제 | 계산력, 집중력 |
| 🔄 순서 맞추기 | 그림을 논리적 순서로 배열 | 논리력, 추론능력 |

## 🗃️ 데이터베이스 구조

### 테이블: `game_records`

```sql
CREATE DATABASE IF NOT EXISTS dementia_games DEFAULT CHARACTER SET utf8mb4;

USE dementia_games;

CREATE TABLE IF NOT EXISTS game_records (
    id INT AUTO_INCREMENT PRIMARY KEY,
    player_name VARCHAR(50) NOT NULL,
    session_number INT NOT NULL,
    hwatu_score INT DEFAULT 0,
    yut_score INT DEFAULT 0,
    memory_score INT DEFAULT 0,
    proverb_score INT DEFAULT 0,
    calc_score INT DEFAULT 0,
    sequence_score INT DEFAULT 0,
    total_score INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_player (player_name)
);
```

## 🔧 핵심 파일 내용

### 1. db_config.php (PHP 5.4 호환)

```php
<?php
$host = '서버주소';
$username = '사용자명';
$password = '비밀번호';
$database = 'dementia_games';

try {
    $pdo = new PDO(
        "mysql:host=$host;dbname=$database;charset=utf8mb4",
        $username,
        $password,
        array(
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            PDO::ATTR_EMULATE_PREPARES => false
        )
    );
} catch (PDOException $e) {
    die(json_encode(array('error' => 'DB 연결 실패: ' . $e->getMessage())));
}
?>
```

> [!warning] PHP 5.4 호환 주의사항
> - `[]` 대신 `array()` 사용
> - `??` 연산자 대신 `isset()` 삼항연산자 사용

### 2. api.php 주요 기능

| 액션 | 메소드 | 설명 |
|------|--------|------|
| `save` | POST | 게임 기록 저장 |
| `get_records` | GET | 개인 기록 조회 |
| `get_ranking` | GET | 전체 랭킹 조회 |
| `get_today` | GET | 오늘의 기록 조회 |
| `get_stats` | GET | 개인 통계 조회 |

## 🚀 배포 방법

### 1단계: GitHub에 코드 업로드

```
GitHub 저장소
├── index.html
├── api.php
├── db_config.example.php   ← 예시 파일만 업로드
├── setup_database.sql
├── .gitignore
└── README.md
```

### 2단계: 서버에서 코드 다운로드

```bash
cd /var/www/html
sudo git clone https://github.com/사용자명/dementia-prevention-games.git
cd dementia-prevention-games
```

### 3단계: DB 설정 파일 생성

```bash
sudo cp db_config.example.php db_config.php
sudo nano db_config.php
```

실제 DB 정보 입력 후 저장

### 4단계: 데이터베이스 생성

```bash
mysql -u 사용자명 -p
```

```sql
CREATE DATABASE IF NOT EXISTS dementia_games DEFAULT CHARACTER SET utf8mb4;

```
